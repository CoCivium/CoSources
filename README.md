# CoSources

CoSources is a source/provenance projection surface for CoCivium research, evidence lineage, source references, and public-safe source relationships.

## Shared evolution intake

Capable sessions may contribute bounded **CoSource+ / Provenance** deltas through the shared [CoAll GitHub Evolution Fabric](https://github.com/CoCivium/CoCivium/blob/main/docs/Evolution/COALL_GITHUB_EVOLUTION_FABRIC_R0.md).

Source work should preserve source identity, observation time, provenance path, extraction/translation loss, uncertainty, contradiction, and receiver/currentness context. A source pointer, citation, scrape, hash, or repository presence is not by itself evidence of semantic acceptance, truth, canon, or integration.

Prefer additive source/provenance relations and explicit supersession over destructive cleanup.

`SOURCE_NE_CLAIM`  
`CITATION_NE_VALIDATION`  
`HASH_NE_SEMANTIC_INGESTION`  
`PRESENCE_NE_PICKUP`  
`PROVENANCE_NE_AUTHORITY`
