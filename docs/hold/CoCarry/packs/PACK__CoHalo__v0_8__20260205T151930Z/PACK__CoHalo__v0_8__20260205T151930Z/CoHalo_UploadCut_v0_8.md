## Intent
Ship CoHalo onboarding + CoHalo page + RepTag vector + CoFeed digest as the XR/gaming soft-launch wedge.

## Core primitive
RepTag = 7-axis CivShift vector + tolerance + coaching intensity.

```text
YouNow -> YouNext

Tribe      ->  Method
Emotion    ->  Evidence
Roles      ->  Consent
Status     ->  Meaning
Stuff      ->  Optionality
Contracts  ->  Renewal
Safety     ->  Managed Risk
```

Encoding:
- AX=_______ (7 digits 0–4)
- TOL=______ (optional)
- CT=_ (0–3)

## Non‑negotiables
- Never require dox for CoHalo/CoFeed.
- Keep alignment, reputation, identity as separate data planes.

## CoFeed (wedge)
Per-item labels:
- Alignment fit: Low/Med/High
- Mindshare hazard: None/Mild/Serious/Severe/Extreme
Output: ranked queue + short “why” + digest.

## CoHalo page (viral surface)
Public default:
- pseudonym(s), CivShift vector, proof-of-control badge(s), earned “update” badges.
Private by default:
- link graph, raw logs, PII, verification details.
